# Harmonious Us — Provisional Alpha System Requirements

These requirements are for the **current Alpha builds** of Harmonious Us and are intentionally conservative for the game's present scope. They will be reviewed as larger worlds, additional planets, simulation depth, visual features, and content are added.

## Windows

| | Minimum | Recommended |
|---|---|---|
| **OS** | Windows 10 64-bit | Windows 11 64-bit |
| **Processor** | Intel Core i5-6500 / AMD Ryzen 3 1200 or equivalent | Intel Core i5-8400 / AMD Ryzen 5 2600 or better |
| **Memory** | **4 GB RAM** | **8 GB RAM** |
| **Graphics** | NVIDIA GTX 750 Ti 2 GB / AMD RX 460 2 GB or equivalent | NVIDIA GTX 1060 3 GB / AMD RX 570 4 GB or better |
| **Graphics API** | DirectX 11 capable | DirectX 11/12 capable |
| **Storage** | **2 GB available space** | **4 GB available space; SSD recommended** |
| **Network** | Broadband Internet required for multiplayer | Broadband Internet required for multiplayer |

## Linux

| | Minimum | Recommended |
|---|---|---|
| **OS** | Ubuntu 22.04 LTS 64-bit or equivalent modern distribution | Ubuntu 24.04 LTS or newer equivalent |
| **Processor** | Intel Core i5-6500 / AMD Ryzen 3 1200 or equivalent | Intel Core i5-8400 / AMD Ryzen 5 2600 or better |
| **Memory** | **4 GB RAM** | **8 GB RAM** |
| **Graphics** | NVIDIA GTX 750 Ti 2 GB / AMD RX 460 2 GB or equivalent Vulkan-capable GPU | NVIDIA GTX 1060 3 GB / AMD RX 570 4 GB or better |
| **Graphics API** | Vulkan capable | Vulkan capable |
| **Drivers** | Current stable NVIDIA driver or Mesa stack | Latest stable NVIDIA driver or Mesa stack |
| **Storage** | **2 GB available space** | **4 GB available space; SSD recommended** |
| **Network** | Broadband Internet required for multiplayer | Broadband Internet required for multiplayer |

## Notes

- These are **Alpha-era provisional requirements**, not final retail specifications.
- Current Windows and Linux client downloads are only a little over 100 MB compressed, but extra free space is reserved for installation, updates, settings, logs, and future Alpha growth.
- Harmonious Us uses procedural generation, persistent world changes, wildlife, farming, building, weather, and multiplayer synchronization. Requirements may increase as those systems grow.
- Solo play does not require an Internet connection. Multiplayer does.
- Final requirements will be based on broader performance testing across representative hardware before Early Access / retail release.
