# Harmonious Us

> **Rebuild civilization from the ground up.**

**Harmonious Us** is a stylized survival and civilization sandbox about humanity relearning how to survive, build, farm, trade, industrialize, automate, and eventually reach new worlds.

This repository is the **official public download hub** for Harmonious Us.

## Download

### Recommended: Harmonious Us Launcher

The launcher is the normal way to install and keep Harmonious Us up to date.

1. Open the **Releases** section on this repository.
2. Download **`HarmoniousUsLauncherSetup.exe`** on Windows.
3. Install and open the launcher.
4. Press **INSTALL**.
5. After installation, press **PLAY**.
6. When a new build is published, reopen the launcher and press **UPDATE**.

The launcher verifies downloaded files before installing them and is designed to preserve player settings while updating the game.

### Linux

Linux client packages and launcher files will also appear in **Releases** as they are published.

### System requirements

Current provisional Alpha requirements for Windows and Linux are available in **[SYSTEM_REQUIREMENTS.md](SYSTEM_REQUIREMENTS.md)**.

The current targets are intentionally modest: **4 GB RAM / 2 GB free space minimum** and **8 GB RAM / 4 GB free space recommended**. They will be revised as the game grows and wider hardware testing is completed.

## What is Harmonious Us?

Humanity became dependent on automation and forgot many of the practical skills that once kept civilization alive.

You begin with almost nothing.

**Survive → Gather → Build → Farm → Trade → Industrialize → Mechanize → Automate → Build a civilization → Reach the stars**

Harmonious Us is built around a simple progression philosophy:

> **First understand the work. Then mechanize the work. Then automate the work.**

### Explore distinct worlds

The game is being built around one persistent civilization spanning multiple planets:

| Planet | Identity |
| --- | --- |
| **Origin** | Balanced forests, plains, mountains, rivers and the beginning of civilization |
| **Khepra** | Volcanic deserts, basalt, heat, smoke, lava and water scarcity |
| **Nivara** | Frozen wilderness, glaciers, blizzards, auroras and thermal survival |
| **Pelagos** | Oceans, islands, reefs, marine resources and water-based civilization |
| **Viridia** | Dense alien jungle, fungi, spores, exotic biology and abundant life |
| **Astraea** | Harsh mineral terrain, crystal fields, rare materials and frontier technology |

Each world is intended to have its own terrain, vegetation, wildlife, resources, recipes, hazards and building identity.

## Public Alpha

Harmonious Us is in active development.

Alpha builds may contain:

- unfinished systems
- placeholder or evolving art
- balance changes
- bugs
- incomplete content
- save or networking changes between major development milestones

Frequent updates are expected. The launcher exists so updating can remain simple as the alpha evolves.

### Current development focus

- stylized low-poly visual overhaul
- large persistent worlds
- multi-planet civilization
- building and crafting
- farming and gathering
- wildlife, hunting and breeding
- planet-specific recipes and materials
- multiplayer persistence
- automation and industry
- interplanetary progression

## Update & Repair

The launcher is designed to:

- detect a newer Harmonious Us release
- download the new client
- verify its SHA-256 checksum
- stage the update before replacing the current build
- keep a previous working installation for rollback
- repair missing or damaged game files

If a server requires a newer client, update through the launcher before reconnecting.

## Release files

Public releases may contain:

- **HarmoniousUsLauncherSetup.exe** — Windows launcher installer
- **HarmoniousUs-Windows-x64-`<version>`.zip** — Windows client
- **HarmoniousUs-Linux-x64-`<version>`.tar.gz** — Linux client
- **manifest-alpha.json** — launcher update manifest
- **SHA256SUMS.txt** — release checksums
- release notes

### Security note

This is a **binary distribution repository only**.

The Harmonious Us source project, internal development tooling, private server configuration and dedicated-server packages are **not distributed from this repository**.
